# 🩺 Multi Disease Prediction System (MDPS)

## 📌 Project Overview

The **Multi Disease Prediction System (MDPS)** is a machine learning-based web application designed to predict the likelihood of three diseases: **Diabetes, Heart Disease, and Parkinson's Disease**. The system uses machine learning algorithms such as **Logistic Regression and Support Vector Machine (SVM)** to analyze relevant health parameters and generate prediction results through an interactive Streamlit user interface.

The primary objective of this project is to demonstrate how machine learning can support preliminary health risk assessment by processing user-provided medical data and providing quick, accessible predictions. By integrating predictive models with a user-friendly web interface, the system aims to make machine learning applications in healthcare easier to explore and understand.

## 🎯 Objectives

- Develop a unified platform for predicting multiple diseases.
- Apply machine learning algorithms to health-related datasets.
- Provide an interactive and user-friendly interface using Streamlit.
- Demonstrate the application of predictive analytics in healthcare.
- Explore how data-driven systems can support preliminary disease risk assessment.

## 🦠 Diseases Covered

- **Diabetes Prediction:** Estimates the likelihood of diabetes based on relevant health indicators.
- **Heart Disease Prediction:** Estimates the likelihood of heart disease using relevant clinical parameters.
- **Parkinson's Disease Prediction:** Uses relevant input features from the dataset to estimate the likelihood of Parkinson's disease.

## 🚀 Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/multi-disease-prediction-system.git
```

**2. Navigate to the project directory**

```bash
cd multi-disease-prediction-system
```

**3. Install the required dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```

The application will open in your browser.
